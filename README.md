# CoreSpoke feedback

CoreSpoke is a small set of developer tools that share one account: KeepAlive (uptime monitoring), Simplify API (secret vault), LLM Router (AI chat with your own key), Dispatch (transactional email) and Flows (visual workflows). Everything is in beta.

This repo is the public place to tell us what to build or fix.

## How it works

1. Open the [Issues tab](https://github.com/CoreSpoke/feedback/issues/new/choose).
2. Pick **Feature request** or **Bug report**.
3. Choose which site it is about and write a short description.
4. We read every issue, add a label (planned, in progress, done) and reply here.

Have a question or an open idea? Use [Discussions](https://github.com/CoreSpoke/feedback/discussions).

Prefer to do it inside the product? Signed-in users can also use the feedback board on the CoreSpoke hub.

## Please do not post

Passwords, API keys, tokens or other private data. Issues here are public.
